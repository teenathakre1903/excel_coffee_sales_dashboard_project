# ☕ Coffee Sales Dashboard

## 📌 Project Overview

An Excel dashboard that analyzes coffee sales data and provides insights into sales performance, customer behavior, and product trends.

---

## 🎯 Objectives

- Analyze sales trends
- Identify top-performing products
- Track revenue
- Monitor customer purchasing behavior

---

## 🛠️ Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Git
- GitHub

---

## 📊 Dashboard Features

- Sales analysis
- Product analysis
- Revenue tracking
- Interactive filters
